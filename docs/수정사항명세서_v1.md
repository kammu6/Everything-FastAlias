## Everything 탐색기 쿼리 파서(Parser) 개선 및 기능 명세서

코딩 AI(LLM)가 즉시 파서(Parser) 로직을 수정하고 테스트 코드를 작성할 수 있도록, UI 버그 수정 사항과 검색 쿼리 빌더의 핵심 규칙을 구조화한 명세서입니다.

---

### 1. UI 및 신규 기능 요구사항 (Front-end)

* **검색 결과 리스트 UI 버그 수정:** * 창이 최대화 상태가 아닐 때, 세로 스크롤바가 생성되면 검색 결과의 가장 하단 줄이 스크롤바 UI에 가려져 보이지 않는 이슈가 있음. 하단 패딩(Padding) 또는 마진(Margin)을 조정하여 가려짐 현상을 해결할 것.

---

### 2. 검색 쿼리 파서(Parser) 핵심 설계 원칙

#### A. 부등호 `< >` 기반의 안전한 그룹화

Everything 엔진이 복합 쿼리를 해석할 때 연산자 우선순위 충돌이 발생하지 않도록, 모든 독립된 조건은 반드시 `< >`로 감싸서(Grouping) 체계적으로 결합해야 합니다.

#### B. 탐색 대상 범위(Scope) 지정 규칙

공백이 포함된 검색어 처리 시, 슬래시(`\`)와 `path:` 키워드를 활용해 명확히 구분합니다. (예: `Lana Rhoades`)

* **전체 (경로+파일명):** `<path:검색어>`
* **파일 (파일명만):** `<nopath:검색어>` (최종 하위 폴더명 포함)
* **경로 (경로만):** `<path:검색어\>` (끝에 슬래시 추가로 구분)

#### C. 폴더 검색 배제 필터 (`file: ext:`)

단순히 `ext:mp4`로 검색할 경우 `이름.mp4` 형태의 **폴더**가 검색되는 예외가 존재합니다. 이를 방지하기 위해 확장자 필터 앞에는 반드시 `file:` 옵션을 조합하여 **`<file: ext:확장자>`** 형태로 묶어 파일만 정확히 타겟팅해야 합니다.

#### D. 🌟 [가장 중요] 따옴표(`""`)와 와일드카드 보호 규칙

Everything에서 큰따옴표(`""`)는 내부의 `*`, `?` 등을 정규 와일드카드가 아닌 '일반 리터럴 문자'로 강제 인식하게 만듭니다. 이를 방지하기 위해 검색어 성격에 따라 따옴표 사용을 엄격히 분리합니다.

1. **별칭(Alias) 처리:** 사전에 정확한 풀네임으로 정의된 값이므로 큰따옴표(`""`)로 묶어 정확하게 일치시킵니다. (예: `<path:"Adriana Chechik">`)
2. **일반 검색어 처리:** 사용자가 와일드카드(`*`, `?`)를 섞어 쓸 수 있도록 **절대 따옴표를 쓰지 않고** 부등호로만 묶습니다. (예: `<path:Adriana *>`)

### 3. 안정적인 쿼리 생성을 위한 4단계 빌드 파이프라인

조건이 추가될 때마다 아래의 순서대로 문자열을 결합(Append)하여 가독성과 파싱 안정성을 확보합니다.

1. **1단계: 검색어 및 별칭(Alias) 결합 (우선순위 1)**
* 입력된 검색어와 Alias를 분석하여 묶습니다. 띄어쓰기가 있는 키워드는 쪼개지 말고 하나의 `< >` 안에 둡니다. "|", " |", "| " 기준으로 쪼갭니다.  Alias 묶음과 일반 검색어 묶음은 OR(`|`) 연산자로 결합합니다.


2. **2단계: 타겟 드라이브 필터 추가 (공간적 제한)**
* 검색 대상 드라이브들을 OR(`|`)로 묶고 부등호로 감쌉니다.
* 예: `<path:K:\ | path:N:\ | path:P:\>`


3. **3단계: 미디어 및 파일 크기 필터 결합 (물리적 필터링)**
* 폴더 방지용 `file:` 필터와 파일 크기(size) 조건을 각각 독립된 부등호로 결합합니다.
* 예: `<file: ext:mp4;mkv;avi>` `<size:>=10mb>`


4. **4단계: 휴지통 및 시스템 폴더 제외 (최종 정제)**
* 노이즈 방지를 위해 `<!$Recycle.Bin>`를 추가합니다. (단, 설정에서 '휴지통 포함(true)'인 경우 이 구문은 생략)

### 4. TDD 기반 쿼리 파싱 테스트 케이스 (As-Is ➡️ To-Be)

코딩 AI는 아래의 `To-Be` 포맷이 정확히 출력되도록 파서 로직(RegEx 또는 Tokenizer)을 리팩토링해야 합니다.

> **[테스트 환경 공통 설정]**
> * Alias: `#back_to_freedom` = `Adriana Chechik;Megan Rain;Ava Addams`
> * 드라이브: `K, N, P` / 탐색 대상: `전체` / 필터: `영상(mp4;mkv;avi;wmv;flv;mov;webm;m3u8;ts)`, `10mb 이상`
> * 대소문자/단어일치/정규식: `false` / 휴지통 포함: `true` (제외 구문 사용 안 함)
> 
> 

#### Case 1: 검색단어 `[ Alias | 일반 검색 ]` 혼합

* **Input:** `#back_to_freedom | Lana Rhoades`
* **To-Be:** ```text
<<[path:"#back_to_freedom"](https://www.google.com/search?q=path:%22%23back_to_freedom%22) | <path:"Adriana Chechik"> | <path:"Megan Rain"> | <path:"Ava Addams">> | <path:Lana Rhoades>> <path:K:\ | path:N:\ | path:P:> <file: ext:mp4;mkv;avi;wmv;flv;mov;webm;m3u8;ts> [size:](https://www.google.com/search?q=size:)=10mb>
```
*(참고: Alias로 치환된 이름들은 따옴표 유지, 일반 검색어 `Lana Rhoades`는 따옴표 없음)*


```



#### Case 2: 검색단어 `[ 일반 검색 + 와일드카드 ]`

* **Input:** `Adriana *`
* **To-Be:** ```text
<path:Adriana *> <path:K:\ | path:N:\ | path:P:> <file: ext:mp4;mkv;avi;wmv;flv;mov;webm;m3u8;ts> [size:](https://www.google.com/search?q=size:)=10mb>
```
*(참고: 와일드카드가 정상 작동하도록 따옴표 배제)*


```

```
